🌟 Cara Tercepat — Bookmarklet Safari:
  1. Klik "📋 Copy Script Bookmarklet" di panel atas
  2. Di Safari, buka halaman mana saja → ⌘+D → simpan di Favorites Bar
  3. Klik kanan bookmark baru di Favorites Bar → Edit Address
  4. Hapus semua isi URL → ⌘+V paste script → Enter
  5. Ganti nama bookmark jadi "📋 Ekstrak SR"
  6. Buka halaman SR di daunjati.my.id
  7. Klik bookmark "📋 Ekstrak SR"
  8. Kembali ke tab aplikasi ini → klik "📥 Ambil & Preview"
💡 Catatan:
• Semua output teks otomatis KAPITAL.
• No. DEPT kosong → otomatis disamakan dengan No. BAG.
• Emergency: v jika centang, kosong jika tidak.
• Aplikasi SR dan Daun Jati harus di browser Safari yang sama (localStorage).
