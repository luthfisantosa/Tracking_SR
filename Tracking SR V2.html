📖 Cara Penggunaan
  1. Buka halaman SR di daunjati.my.id, lalu Ctrl+P → Save as PDF.
  2. Set No. Rekap Terakhir dan No. JP Terakhir di Konfigurasi sesuai data terbaru Excel.
  3. Upload PDF (bisa banyak sekaligus), tunggu status library PDF.js ✅ Siap.
  4. Klik Proses Scraping — setiap file akan memunculkan modal preview.
  5. Cek & edit hasil ekstraksi di modal, lalu klik Konfirmasi & Tambahkan.
  6. Klik 📋 Copy di baris yang diinginkan → paste ke Excel kolom A baris baru.
💡 Tips:
• Kolom B s/d H (DATE OUT, persetujuan, dll) dikosongkan — isi manual setelah proses persetujuan.
• Emergency: v jika ada centang di form, kosong jika tidak.
• Nama Pekerjaan diambil dari field "NAMA PEKERJAAN JASA (40 Karakter...)" — nilai sebelah kanannya.
• Kolom P (Lingkup) diisi sama dengan Nama Pekerjaan secara default; edit manual jika perlu.
